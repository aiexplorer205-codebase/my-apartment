# Security policy

MyApartment by BLOCK9 is under active development. There are no production-supported releases.

## Reporting a vulnerability

Do not report suspected vulnerabilities in a public issue or pull request. Use GitHub private vulnerability reporting if it is enabled; otherwise contact the repository owner on a private channel. Include enough to reproduce without real resident data, credentials, or production systems.

Do not test against systems, accounts, or data you do not own or have explicit authorization to assess.

Security fixes target the current default development branch.

Never commit secrets, database locators, tokens, real resident information, or production configuration. Product constraints: [docs/security-and-ops.md](docs/security-and-ops.md).
